# NRT — client indicators and dashboards

Client work includes TradingView/Pine Script indicators and dashboard components. The public showcase spans earnings, trend, accumulation/distribution, breakout and speed indicators.

## Implementation leadership

I led Neely River's TradingView implementation, translating Glenn's methodology into indicators and dashboard components. I coordinated requirements and feedback, guided testing and releases, and supported onboarding. Glenn's methodology remains his; my role focused on implementing it in TradingView and guiding that implementation through feedback and testing. This work does not imply a completed v1.0 launch.
